# 2.0.1-beta.2 发布前检查

本次用户授权将此前修复以测试版推送给用户。目标版本为 2.0.1-beta.2，开发分支为 codex/2.0；不合并 main，不覆盖本机安装。

## 发布范围

- 硬盘主温度选择：先按磁盘选择 Composite／主温度，再比较各盘；不将控制器、NAND、热点和阈值作为主温度。
- 竖排透明合成：绑定顶层透明宿主，保持中间 HWND 隐藏，配套修正尺寸消息、鼠标转发、显隐与清理。发布前修正 Windows API 可选输出指针参数类型。
- 只读窗口诊断工具：明确 UTF-8 读取，在 Windows PowerShell 5.1 遇到配置错误时仍保留窗口证据。
- 同步产品版本、应用与安装器清单及两份 Cargo.lock 中的产品版本，不升级依赖。
- PUBG 用户取消 TslGame.exe 的“禁用全屏优化”后反馈 OSD 恢复。此结果写入兼容性说明；不修改游戏配置、注册表或采集链路，也不将其包装成代码修复。

## 验证边界

上述检查没有启动游戏、独立透明度窗口或 UAC 实验。竖排透明效果、拖动／穿透、显隐与重启定位仍需测试版用户实机验收；不以编译或单元回归宣称视觉效果已通过。

本记录只证明发布前源码检查。隔离构建、最终 payload、签名和远端附件校验结果由本轮 release-evidence 与本地日志另行记录，不能从本记录推断已经完成发布。
