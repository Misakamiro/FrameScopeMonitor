# 2.0.1-beta.3 发布前检查

用户授权将当前已修复、已本机更新的版本作为测试版推送给用户。GitHub 发布前的最新测试版为 2.0.1-beta.2；本轮发布未公开的 2.0.1-beta.3，保持 codex/2.0 开发分支及 2.0.0 正式渠道。

## 范围

- 随 Windows 启动设置、登录后直接进入托盘及手动启动托盘选项。
- 报告辅助线画布按物理像素完整清屏。
- 更新器系统代理、证书、实际安装包线路测速及持续低速回退。
- 双显卡按设备标识保持选择、缺失读数到期清空。
- 退出与关机时阻止重新启动硬件进程。
- 全局搜索二级菜单和具体设置，定位、键盘与刷新稳定性。
- 竖排透明宿主的窗口类修正，以及 WebView2 合成控制器创建时的背景设置。

逐文件实现、失败复现和此前本机验收见同目录的 2026-10-22-six-issues.md、2026-10-22-updater-speed.md、2026-10-22-search.md 与 2026-10-21-composition-background-options.md。本机 Mica For Everyone 的例外配置不是发行包的一部分，也不宣称 WebView2 背景设置能覆盖第三方全局背板规则。

## 发布检查

本轮重新执行前端 Vitest（18 文件、89 项）、类型检查、主程序 Rust（99 项）、更新器 Rust（22 项）、硬件服务 Rust（87 项单元测试）、C# 报告完整性/恢复、硬件关机保护及安装退出检查，均通过。真实 Edge 画布回归在 DPR .5/.8/1/1.25/2 下没有残留像素；控制器背景 API 顺序/兼容回退的 10 项检查通过。发布清单、payload 与完整安装包附件策略的工具测试通过。

安装器 Rust 回归及管理员独立管道测试的最终结果，与构建、签名、远端附件逐项哈希核对及公开更新渠道验证，记录在本机 artifacts/20261022-beta3-release 中；本文不是发布完成凭据。普通权限执行真实管道测试时得到 Windows 拒绝访问，必须在管理员环境重跑，不能将权限失败掩盖为通过。

发布前按审查清单检查进程退出门控、计划任务参数/归属、签名与哈希链路、GPU 身份与 TTL、设置 URL 和搜索定位边界；未增加与本次修复无关的功能。三个功能提交分别保留运行链路、WebView2 合成和搜索修复，发布提交更新变更说明。

## 构建来源与验收边界

复用 C:\fs-build\b203 的现有隔离源码和缓存，先备份旧输入清单、结果和派生配置，再将隔离源码快进到本轮已提交的发行源码，重新逐项核对输入并生成本轮清单。不新增第三套完整源码副本，不将先前带 componentOverride 的本机组件候选冒充全量发行。构建使用生产 custom-protocol，不加入 uiaccess-acceptance 诊断功能。

全量重新构建 C#/Rust 后端、当前前端、宿主和安装器；重新生成完整 payload 及版本/SHA 元数据。标准包使用 Minisign 签名的更新清单，完整包绑定同一标准包并内含经固定哈希与微软签名校验的 WebView2 运行时。现有公开标签和附件不覆盖。

真实登录、双显卡反馈电脑的游戏、各用户代理环境和实际关机仍属于测试版验收范围。本轮不注销、关机或卸载用户当前软件；安装事务的首次安装、覆盖、卸载和数据保留/删除路径由安装器回归覆盖，不将事务模拟等同于完整 Windows 系统生命周期实测。历史 HTML 需重新生成才包含清屏修复。

用户本机已接受的搜索候选及其配置/历史/Mica 例外继续保留；若同步正式发行文件，单独记录正常退出、备份、文件哈希、实时数据和重启结果。程序回退使用经过验证的上一版或本机备份；公开版本不改写，后续修复使用更高版本。
