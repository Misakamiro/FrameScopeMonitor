# README 配图来源

所有图片于 2026-11-02 重新生成，不复用旧验收图。主页、硬件和榜单来自当前 2.1.2 源码构建的隔离原生宿主，使用独立应用标识和 WebView 数据目录。构建时只覆盖截图宿主配置，未修改产品渲染代码。

| 图片 | 数据与取得方式 |
| --- | --- |
| home-mr / home-light | 当前原生 WebView 截图；演示硬件清单，MR 或自制渐变背景。 |
| hardware | 当前原生 WebView；演示配置及部分本机实时传感器，不代表游戏负载。 |
| leaderboard-full | 当前完整版原生页面；截取数据接口的隔离合成用户和成绩，不含生产榜单记录。 |
| osd-vertical | 当前原生 OSD 窗口，使用 PrintWindow 重新截图；本机传感器，无游戏帧数据，因此 FPS / Low 为 --。 |
| report | 本轮 2.1.2 生成器读取新建合成帧、进程和系统 CSV 后生成的实际网页报告。 |

这些是当前软件的界面展示，不代表真实游戏测试、性能比较或 Windows 桌面穿透验收。演示输入不修改软件统计。源码版本和图片分别经过核对，公开文件为原始截图的 WebP 压缩版本。上游说明见 [第三方声明](../../THIRD-PARTY-NOTICES.md)。
