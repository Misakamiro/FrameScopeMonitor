# WebView2 离线完整版安装包

用户要求提供可用于缺少 WebView2 的电脑的安装包。当前 Tauri 安装器的检测命令在 WebView 界面创建后运行，无法解决冷启动依赖缺失。

采用独立的 .NET Framework 原生引导程序，内置已经公开、签名清单验证通过的标准安装器及依赖锁固定的微软 Evergreen x64 离线安装程序。引导程序不创建 WebView；先按微软文档查询机器／当前用户、32／64 位注册表视图中的 WebView2 Runtime GUID 和有效版本。

缺少运行时时先启动微软安装程序；重新检测成功后启动原标准安装器。已有运行时直接进入软件安装。依赖取消、失败或需要重启时停止，不修改 FrameScope 的安装文件。提取文件逐项校验 SHA256，原安装参数通过 Windows 参数引用规则转交；引导程序使用正常 UAC。

完整版是现有应用的打包变体，产品 VERSION 保持 2.0.0，应用仍对应原提交 3c8d21e。独立签名清单记录引导程序提交、应用提交、完整版哈希及两个内置文件的大小和哈希。为同一 Release 增加完整包和独立签名清单，不覆盖原标签、标准包或标准更新清单。客户端继续从原标准更新清单升级。

验证包含依赖缺失／已安装／取消／失败／重启、退出码、文件损坏、参数引用，构建后读取真实程序集资源校验全部字节，发布后重新下载核对全部六份附件并复查客户端更新查询。夹具不代表在缺少 WebView2 的干净机器上完成真实安装；本机不卸载共享运行时，不覆盖 FrameScope。
